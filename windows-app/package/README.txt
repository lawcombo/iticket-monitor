iTicket 서버 모니터 위젯
=========================

[설치]
1. 압축을 해제합니다.
2. install.cmd를 더블클릭합니다.
3. 화면 오른쪽 위에 신호등 위젯이 표시됩니다.
4. 첫 실행 시 API Bearer 토큰을 입력합니다.

[사용]
- 위젯 클릭: 상세 GitHub Pages 화면 열기
- 위젯 드래그: 화면 위치 이동
- 위젯 우클릭: 즉시 점검, 서버 ON/OFF, 주기, 자동 실행, 종료
- 토큰은 현재 Windows 사용자만 해독할 수 있도록 암호화해 저장됩니다.
- 정상 초록 / 지연·이상 주황 / 장애 빨강 / 점검 중 파랑

[설정]
- 설정은 %LOCALAPPDATA%\iticket-monitor\widget.ini에 저장됩니다.
- URL을 직접 바꾼 뒤 프로그램을 다시 실행하면 반영됩니다.

[제거]
- uninstall.cmd를 더블클릭합니다.
- 설정 파일은 재설치를 위해 남겨둡니다.
